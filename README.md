# Employee Management API

A RESTful Web API built using ASP.NET Core for managing employee records, departments, and related operations.  
This project demonstrates clean architecture principles, CRUD operations, and API development using modern backend technologies.

---

## Features

- Create, Read, Update, and Delete (CRUD) employee records
- RESTful API architecture
- Entity Framework Core integration
- Database migrations support
- Clean separation using Services and Interfaces
- Scalable backend structure
- Error handling and validation

---

## Tech Stack

- ASP.NET Core (.NET 8)
- Entity Framework Core
- SQLite / SQL Server
- C#
- REST APIs
- Swagger (API testing)
